# End-to-end journeys

## Critical

- Configure a workout, pull and reroll a ticket, edit bookends, start the
  countdown, follow the run display, and finish either naturally or early.
- Reload the previously loaded app offline and reach the workout configurator.
- Produce a result PNG through the download fallback when native file sharing
  is unavailable.

## Platform guidance

- On iPhone Safari, explain the Add to Home Screen steps.
- On compatible Chromium browsers, surface the native install prompt without
  blocking workout generation.
